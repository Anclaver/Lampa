# Lampa Plugins

- **Favorite Plus**
  Свои категории в Избранном: создание, переименование и удаление. Добавление фильма/сериала прямо из карточки.
- **Favorite Poster**
  Обновляет постеры фильмов/сериалов в Избранном свежими изображениями.
- **UI Badge**
  Показывает на карточках тип, длительность, прогресс просмотра, качество, рейтинг. Цветная индикация.
- **UI Style**
  Добавляет на странице фильма/сериала оригинальное название, кнопки Онлайн/Торрент впереди. Убирает подтверждение выхода из приложения. На телефоне добавляет «Избранное» в нижнюю панель.
