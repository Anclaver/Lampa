# Lampa Plugins

- **Favorite Plus**
  Свои категории в Избранном: создание, переименование и удаление. Добавление фильма/сериала прямо из карточки.
- **Favorite Refresh**
  Обновляет постеры и названия фильмов/сериалов в Избранном свежими данными.
- **UI Badge**
  Показывает на карточках тип, длительность, прогресс просмотра, качество, рейтинг. Цветная индикация.
- **UI Style**
  Добавляет на странице фильма/сериала оригинальное название, кнопки Онлайн/Торрент впереди. В списке торрентов раскладывает характеристики видео, аудио и субтитров в три ряда. Убирает подтверждение выхода из приложения. На телефоне добавляет «Избранное» в нижнюю панель.
