# Lampa Plugins

- **Favorite Plus** — Свои категории в Избранном: создание, переименование и удаление. Добавление фильма/сериала прямо из карточки.
- **Favorite Poster** — Обновляет постеры фильмов/сериалов в Избранном свежими изображениями.
- **UI Badge** — Показывает на карточках тип, длительность, прогресс просмотра, качество, рейтинг. Цветная индикация.
- **UI Style** — Делает интерфейс компактнее, вмещает больше карточек, регулировка размера через меню. На странице фильма/сериала кнопки Торрент/Онлайн впереди, добавляет оригинальное название.
- **UI Mobile** — Добавляет кнопку «Избранное» в нижнюю панель на телефоне — до нужного раздела всегда один тап.
- **UI Exit** — Убирает подтверждение выхода из приложения.
